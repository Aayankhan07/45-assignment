## 2024-05-01 - O(N*M) nested loop using some() to Sets O(N+M)
**Learning:** Found an O(N*M) iteration loop checking two arrays using `some()`. Creating a `Set` allows O(1) lookups and changes it to an O(N+M) complexity code.
**Action:** When working on arrays that map data checks, use `Set` for lookups instead of nested `.some()` or nested arrays loops.
