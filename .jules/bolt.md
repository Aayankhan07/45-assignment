## 2024-05-24 - V8 Set Initialization Overhead
**Learning:** For very small arrays (e.g., 5 elements), mapping an array to lowercase and using `.includes()` can be slightly faster than converting to a `Set` and using `.has()`. The overhead of instantiating a `Set` dominates the O(1) lookup benefit when N is extremely small. However, as array size grows (even to just 100 elements), the `Set` approach becomes vastly superior (e.g., ~10x faster) due to eliminating the O(N*M) time complexity.
**Action:** When optimizing O(N*M) array loops (like checking if items exist in another list with some transformation like `toLowerCase()`), always pre-compute the transformation and use a `Set` for lookups, as the data size might grow and the semantic intent (O(1) lookup) is clearer, unless it's guaranteed to always be a microscopic array in a wildly hot path where Set creation overhead is proven to be the bottleneck.
